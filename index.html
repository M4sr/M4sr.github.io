Menitgaming Uploader

Internal publishing tool for the YouTube channel @menitgaming.

What this is

A private, single-operator utility that uploads video files owned by the channel operator to that same channel. It is not a public service, has no users other than the channel owner, and is not distributed or offered for sign-up.

Google API usage

It requests exactly one OAuth scope: https://www.googleapis.com/auth/youtube.upload. It cannot read, modify or delete existing channel data and cannot access any other Google account.
